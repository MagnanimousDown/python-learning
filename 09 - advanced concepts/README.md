# Session vs JWT

## JWT
```
Server -> Creates token
Browser -> Stores token
Browser -> Sends token on every request
Server -> Verifies signature
```

## Flask Session (default)
```
Server -> Creates session data
Flask -> Signs it using SECRET_KEY
Browser -> Stores signed cookie
Browser -> Sends cookie automatically
Flask -> Verifies signature
```

The major difference:
- JWT is commonly sent in the Authorization header.
- Session cookies are automatically sent by the browser.

## CSRF:
Cross Site Request Forgery - A different site forged a request on behalf of the user.

## What is CSRF?
CSRF is an attack where a malicious website tricks a logged-in user's browser into sending an authenticated request to another website. CSRF tokens prevent this by ensuring that state-changing requests originate from legitimate forms generated by the application itself.

CSRF token is:

Generated by server
Embedded into the legitimate form
Submitted back with the form
Verified by server
Cannot be read by other websites because of Same-Origin Policy

So the attacker can force the victim's browser to send cookies, but cannot force it to send the correct CSRF token.
